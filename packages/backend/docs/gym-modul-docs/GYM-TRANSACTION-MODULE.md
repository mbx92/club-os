# 💰 Transaction Module Integration - Gym Membership System

## 📋 Overview

Modul Transaction adalah **unified transaction system** yang menangani semua jenis penjualan:
- Membership purchase
- Class package purchase  
- Combined purchase (membership + class package)
- Future: POS products

Transaction menggunakan **race-condition safe** auto-numbering dan terintegrasi penuh dengan voucher system.

---

## 🎯 Architecture

### Transaction Hierarchy

```
Transaction (Header)
├── transactionNumber: "TRX-20251123-0001" (auto-generated)
├── tenantId: per-tenant isolation
├── customerId: member ID
├── voucherId: optional voucher
├── subtotal: sum of items before tax/discount
├── tax: from tenant settings
├── voucherDiscount: calculated from voucher
├── totalAmount: final amount
│
├─── TransactionItem[] (Line Items)
│    ├── itemType: 'membership' | 'class_package' | 'product'
│    ├── itemId: FK to MembershipPlan | ClassPackagePlan | Product
│    ├── quantity
│    ├── unitPrice
│    └── total
│
└─── TransactionPayment[] (Payments)
     ├── paymentMethod: 'cash' | 'credit_card' | 'transfer' | etc
     ├── amount
     └── status: 'completed' | 'pending' | 'failed'
```

## 🔧 Key Features

### 1. Auto-Numbering (Race-Condition Safe)

```javascript
// Migration sudah ada sequence table
// Transaction model hook:
beforeCreate: async (transaction, options) => {
  if (!transaction.transactionNumber) {
    const date = new Date();
    const prefix = `TRX-${date.getFullYear()}${String(date.getMonth() + 1).padStart(2, '0')}${String(date.getDate()).padStart(2, '0')}-`;
    
    transaction.transactionNumber = await ConcurrencyUtils.generateUniqueSequence(
      Transaction,
      { tenantId: transaction.tenantId, transactionNumber: { [Op.like]: `${prefix}%` } },
      prefix,
      options.transaction
    );
  }
}
```

## 🛠️ Complete Transaction Flow

### Flow: Beli Membership via POS

```javascript
/**
 * Create transaction for membership purchase
 */
async function purchaseMembership(req, res) {
  const transaction = await sequelize.transaction();
  
  try {
    const { tenantId } = req.user;
    const { memberId, membershipPlanId, voucherCode, paymentMethod } = req.body;
    
    // 1. Get member & plan
    const member = await Member.findByPk(memberId);
    const plan = await MembershipPlan.findByPk(membershipPlanId);
    
    // 2. Get tenant for tax calculation
    const tenant = await Tenant.findByPk(tenantId);
    const taxEnabled = tenant.settings?.taxEnabled || false;
    const taxRate = tenant.settings?.taxRate || 0;
    
    // 3. Calculate subtotal
    const subtotal = plan.price;
    
    // 4. Apply voucher if provided
    let voucherDiscount = 0;
    let voucherId = null;
    
    if (voucherCode) {
      const voucher = await Voucher.findOne({
        where: { tenantId, code: voucherCode, isActive: true },
        transaction
      });
      
      if (voucher && voucher.isValid() && voucher.isApplicableTo('membership', plan.id)) {
        voucherDiscount = voucher.calculateDiscount(subtotal);
        voucherId = voucher.id;
        
        // Increment voucher usage atomically
        await voucher.increment('usageCount', { transaction });
      }
    }
    
    // 5. Calculate tax
    const tax = taxEnabled ? ((subtotal - voucherDiscount) * taxRate / 100) : 0;
    
    // 6. Calculate total
    const totalAmount = subtotal - voucherDiscount + tax;
    
    // 7. Create Transaction
    const txn = await Transaction.create({
      tenantId,
      customerId: memberId,
      customerType: 'member',
      transactionDate: new Date(),
      subtotal,
      tax,
      discount: 0,
      voucherId,
      voucherDiscount,
      totalAmount,
      status: 'pending',
      createdBy: req.user.id
    }, { transaction });
    
    // transactionNumber auto-generated by hook
    
    // 8. Create TransactionItem
    await TransactionItem.create({
      transactionId: txn.id,
      itemType: 'membership',
      itemId: plan.id,
      itemName: plan.name,
      quantity: 1,
      unitPrice: plan.price,
      subtotal: plan.price,
      discount: voucherDiscount,
      tax: tax,
      total: totalAmount
    }, { transaction });
    
    // 9. Create TransactionPayment
    await TransactionPayment.create({
      transactionId: txn.id,
      paymentMethod,
      amount: totalAmount,
      paymentDate: new Date(),
      status: 'completed'
    }, { transaction });
    
    // 10. Update transaction status
    await txn.update({ status: 'completed' }, { transaction });
    
    // 11. Create/Update Membership record
    const startDate = new Date();
    const endDate = plan.calculateEndDate(startDate);
    
    await Membership.create({
      tenantId,
      memberId,
      membershipPlanId: plan.id,
      startDate,
      endDate,
      status: 'active',
      purchaseTransactionId: txn.id
    }, { transaction });
    
    // 12. Update member status
    await member.update({
      membershipStatus: 'active'
    }, { transaction });
    
    // 13. Create voucher usage record
    if (voucherId) {
      await VoucherUsage.create({
        voucherId,
        userId: req.user.id,
        memberId,
        transactionId: txn.id,
        discountAmount: voucherDiscount
      }, { transaction });
    }
    
    await transaction.commit();
    
    // Return response
    res.status(201).json({
      success: true,
      message: 'Membership purchased successfully',
      data: {
        transactionNumber: txn.transactionNumber,
        totalAmount: txn.totalAmount,
        membership: {
          startDate,
          endDate,
          status: 'active'
        }
      }
    });
    
  } catch (error) {
    await transaction.rollback();
    throw error;
  }
}
```

### Flow: Combined Purchase (Membership + Class Package)

```javascript
async function combinedPurchase(req, res) {
  const transaction = await sequelize.transaction();
  
  try {
    const { tenantId } = req.user;
    const { 
      memberId, 
      membershipPlanId, 
      classPackagePlanId, 
      voucherCode, 
      paymentMethod 
    } = req.body;
    
    // Fetch all resources
    const member = await Member.findByPk(memberId);
    const membershipPlan = await MembershipPlan.findByPk(membershipPlanId);
    const classPackagePlan = await ClassPackagePlan.findByPk(classPackagePlanId);
    const tenant = await Tenant.findByPk(tenantId);
    
    // Calculate subtotal
    const subtotal = parseFloat(membershipPlan.price) + parseFloat(classPackagePlan.price);
    
    // Apply voucher
    let voucherDiscount = 0;
    let voucherId = null;
    
    if (voucherCode) {
      const voucher = await Voucher.findOne({
        where: { tenantId, code: voucherCode, isActive: true },
        transaction
      });
      
      if (voucher && voucher.isValid()) {
        // Check if voucher applicable to all items
        const applicableToMembership = voucher.isApplicableTo('membership', membershipPlan.id);
        const applicableToClass = voucher.isApplicableTo('class_package', classPackagePlan.id);
        
        if (voucher.applicableTo === 'all' || (applicableToMembership && applicableToClass)) {
          voucherDiscount = voucher.calculateDiscount(subtotal);
          voucherId = voucher.id;
          await voucher.increment('usageCount', { transaction });
        }
      }
    }
    
    // Calculate tax
    const taxEnabled = tenant.settings?.taxEnabled || false;
    const taxRate = tenant.settings?.taxRate || 0;
    const tax = taxEnabled ? ((subtotal - voucherDiscount) * taxRate / 100) : 0;
    
    // Total amount
    const totalAmount = subtotal - voucherDiscount + tax;
    
    // Create Transaction
    const txn = await Transaction.create({
      tenantId,
      customerId: memberId,
      customerType: 'member',
      transactionDate: new Date(),
      subtotal,
      tax,
      discount: 0,
      voucherId,
      voucherDiscount,
      totalAmount,
      status: 'pending',
      createdBy: req.user.id
    }, { transaction });
    
    // Create Transaction Items
    await TransactionItem.create({
      transactionId: txn.id,
      itemType: 'membership',
      itemId: membershipPlan.id,
      itemName: membershipPlan.name,
      quantity: 1,
      unitPrice: membershipPlan.price,
      subtotal: membershipPlan.price,
      discount: 0,
      tax: 0,
      total: membershipPlan.price
    }, { transaction });
    
    await TransactionItem.create({
      transactionId: txn.id,
      itemType: 'class_package',
      itemId: classPackagePlan.id,
      itemName: classPackagePlan.name,
      quantity: 1,
      unitPrice: classPackagePlan.price,
      subtotal: classPackagePlan.price,
      discount: 0,
      tax: 0,
      total: classPackagePlan.price
    }, { transaction });
    
    // Create Payment
    await TransactionPayment.create({
      transactionId: txn.id,
      paymentMethod,
      amount: totalAmount,
      paymentDate: new Date(),
      status: 'completed'
    }, { transaction });
    
    // Update transaction status
    await txn.update({ status: 'completed' }, { transaction });
    
    // Create Membership
    const membershipStartDate = new Date();
    const membershipEndDate = membershipPlan.calculateEndDate(membershipStartDate);
    
    await Membership.create({
      tenantId,
      memberId,
      membershipPlanId: membershipPlan.id,
      startDate: membershipStartDate,
      endDate: membershipEndDate,
      status: 'active',
      purchaseTransactionId: txn.id
    }, { transaction });
    
    // Create ClassPackage
    const packageValidUntil = new Date();
    packageValidUntil.setDate(packageValidUntil.getDate() + classPackagePlan.validityDays);
    
    await ClassPackage.create({
      tenantId,
      memberId,
      classPackagePlanId: classPackagePlan.id,
      totalSessions: classPackagePlan.sessions,
      remainingSessions: classPackagePlan.sessions,
      validUntil: packageValidUntil,
      status: 'active',
      purchaseTransactionId: txn.id
    }, { transaction });
    
    // Update member status
    await member.update({ membershipStatus: 'active' }, { transaction });
    
    // Create voucher usage if applicable
    if (voucherId) {
      await VoucherUsage.create({
        voucherId,
        userId: req.user.id,
        memberId,
        transactionId: txn.id,
        discountAmount: voucherDiscount
      }, { transaction });
    }
    
    await transaction.commit();
    
    res.status(201).json({
      success: true,
      message: 'Purchase completed successfully',
      data: {
        transactionNumber: txn.transactionNumber,
        totalAmount: txn.totalAmount,
        items: {
          membership: { startDate: membershipStartDate, endDate: membershipEndDate },
          classPackage: { sessions: classPackagePlan.sessions, validUntil: packageValidUntil }
        }
      }
    });
    
  } catch (error) {
    await transaction.rollback();
    throw error;
  }
}
```

## 📊 Database Sequence for Race Condition

Existing `sequences` table digunakan untuk:
- Transaction number generation
- Invoice number generation
- Voucher code generation

**Transaction number format:**
```
TRX-YYYYMMDD-NNNN
TRX-20251123-0001
TRX-20251123-0002
...
```

Auto-generated via `ConcurrencyUtils.generateUniqueSequence()` dengan pessimistic locking.
